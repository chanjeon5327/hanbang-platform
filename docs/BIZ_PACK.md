# 한방 플랫폼 비즈니스 팩

> 홍보/마케팅/제휴 협상용 산출물

---

## 1) 한 줄 소개 (가치제안)

**디지털 IP 수익권, 3초 만에 투자 시작** — 크리에이터·콘텐츠의 미래 수익을 지금 구매하고, 수익이 발생할 때마다 분배받는 투자 플랫폼

---

## 2) 타겟

| 구분 | 설명 |
|------|------|
| **투자자** | 디지털 자산에 분산 투자하고 싶은 개인 투자자, 팬덤 경제 참여자 |
| **크리에이터** | 유튜브·웹툰·음원 등 IP 보유자, 수익 사전 모집·자금 조달 필요 |
| **파트너** | MCN, 커머스, PG, 법무/회계, 미디어 등 B2B 협력사 |

---

## 3) 제휴 유형 6종

| 유형 | 대상 | 협업 포인트 |
|------|------|-------------|
| **크리에이터** | 유튜버, 웹툰 작가, 음원 아티스트 | 수익권 상장, 팬덤 투자 유도 |
| **MCN** | 멀티채널 네트워크 | 크리에이터 포트폴리오 연계 |
| **커머스** | 이커머스, 라이브커머스 | IP 상품 연계, 수익권 결제 |
| **PG** | 결제 대행사 | 청약/매수 결제, 정산 연동 |
| **법무/회계** | 법인, 회계사 | 투자 구조 검토, 세무 자문 |
| **미디어** | 뉴스, 인플루언서 | 투자 교육, 사례 공유 |

|------|------|------|

| **스폰서 슬롯** | 홈·마켓 광고 위치 | 월 정액/CPM |

| **크리에이터 수익 분배** | 수익권 판매 대금 중 플랫폼 수수료 차감 후 정산 | 70~85% 크리에이터 |

## 9) 협업 제안 DM 템플릿 3종

### A) 크리에이터용

```
안녕하세요, [크리에이터명]님.

한방 플랫폼은 팬분들이 [님의 콘텐츠] 미래 수익에 투자할 수 있는 수익권 마켓을 운영하고 있습니다.

[님의 채널/작품]이 상장되면, 팬들이 지금 참여해 나중에 발생하는 수익을 함께 나눌 수 있습니다. 
팬덤 경제 참여와 동시에 초기 자금 조달에도 도움이 됩니다.

간단한 상담 요청만 부탁드립니다.
```

### B) MCN용

```
안녕하세요, [MCN명] 담당자님.

한방 플랫폼은 디지털 IP 수익권 투자 마켓을 운영 중입니다.

보유 크리에이터 포트폴리오 중 수익권 상장 후보를 함께 발굴하고, 
팬덤 투자·수익 분배 구조를 구축하는 협업을 제안드립니다.

제휴 미팅 일정만 조율해 주시면 감사하겠습니다.
```

### C) 브랜드/커머스용

```
안녕하세요, [브랜드/사명] 담당자님.

한방 플랫폼은 IP 수익권 투자와 커머스 연계를 확장하고 있습니다.

[브랜드/상품]과 IP 수익권을 결합한 프로모션, 
또는 수익권 구매 시 [혜택] 연동 등 다양한 협업 모델을 검토 중입니다.

협업 제안서와 미팅 아젠다를 보내드리겠습니다.
```
