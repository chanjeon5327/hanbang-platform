# HANBANG 데모 동선 체크리스트

> 내부 실무용 · 투자자/파트너 데모 전 반드시 확인  
> 최종 업데이트: 2026-03-11 (데모 실전 준비 1차 반영)

---

## 1. 데모 목적

- K-콘텐츠 IP 수익권 거래 플랫폼의 핵심 UX 흐름을 5분 이내로 전달
- "홈 진입 → 종목 탐색 → 거래 → 자산 확인" 동선의 완성도 증명
- 투자자/파트너에게 서비스 첫인상과 금융형 UI 완성도를 보여주는 것이 목적

---

## 2. 데모 시작 URL

```
https://[배포 도메인]/
```

- 로컬: `http://localhost:3000/`
- **데모 계정 사전 로그인 필수** (아래 준비 체크리스트 참고)

---

## 3. 데모 계정 준비 상태 (필수)

| 항목 | 필요 상태 | 확인 방법 |
|---|---|---|
| 로그인 | 완료 | `/wallet` 접근 시 리다이렉트 없으면 OK |
| 보유 종목 | 1건 이상 | `/wallet` → 보유 종목 섹션 |
| 예수금 | 0원 이상 | `/wallet` → 총 평가 자산 |
| KYC 상태 | 심사 전 또는 승인 | `/kyc` → 상태 배지 확인 |
| 배당 내역 | 없어도 무방 | EmptyState 문구 자연스러움 |

> **중요**: 보유 종목이 0건이면 `/wallet` 보유 종목 섹션이 EmptyState로 표시됨.  
> 데모 전 반드시 mock 투자 1건 이상 세팅할 것.

## 4. 각 화면별 "비어 있으면 안 되는 요소"

### 홈 (`/`)
- ✅ 히어로 영상 재생 중 (검정 배경 아님)
- ✅ 추천 큐레이팅 레일 카드 10개 표시
- ✅ "지금 주목받는 콘텐츠" 그리드 4개 표시
- ✅ 마감 임박 레일 카드 표시
- ✅ 한류지수 차트 렌더링 완료
- ✅ 시장 동향 4개 카드 + 아이콘 micro-motion 동작
- ✅ 뉴스 3개 카드 표시

### 대표 상세 (`/market/[id]`)
- ✅ 종목명 + 현재가 카드 표시
- ✅ 살까말까 탭: 투자 포인트 / 리스크 / 로드맵 불릿 표시
- ✅ 살까말까 탭: **투자설명서 PDF 카드 (full-width)** 표시
- ✅ 지금얼마 탭: 가격 차트 렌더링 완료
- ✅ 거래하기 탭: 주문 패널 표시

### KYC (`/kyc`)
- ✅ 상태 배지 (심사 전 / 심사 중 / 승인) 표시
- ✅ 진행 단계 pill 3개 표시
- ✅ 폼 필드 표시 (승인 상태면 폼 없음 — 정상)

### 마이페이지 (`/mypage`)
- ✅ 총 자산 요약 카드 (₩12,340,000 mock 표시)
- ✅ 투자 중인 작품 2건 표시
- ✅ 기록 섹션 (주문/정산/입출금 링크) 표시

### 지갑 (`/wallet`)
- ✅ 4개 요약 카드 (총자산/미실현손익/수익률/보유종목) 로딩 완료
- ✅ 총 평가 자산 수치 표시
- ✅ 입금/교환/출금 CTA 3버튼 표시
- ⚠️ 보유 종목: **데모 계정에 투자 내역 있어야 함** (없으면 EmptyState)
- ⚠️ 최근 배당: 없어도 "아직 배당 내역이 없습니다" 문구 자연스러움

## 5. 추천 동선 (5단계)

### Step 1 — 홈 (`/`)
- 히어로 섹션 (블루/퍼플 시네마틱 배경 + 영상 + "투자 시작" CTA)
- 추천 큐레이팅 레일 스크롤
- 시장 동향 섹션 (아이콘 micro-motion 확인)

### Step 2 — 대표 상세 (`/market/[id]`)
- 추천 종목: `블루웨이 시즌3` (여행가 제이) 클릭
- 살까말까 탭 → 투자 포인트 / 리스크 / **PDF 카드** 확인
- 지금얼마 탭 → 가격 차트 + 체결 흐름 확인
- 거래하기 탭 → 주문 패널 확인

### Step 3 — KYC (`/kyc`)
- 마이페이지 → KYC 인증 진입
- 상태 카드 + 진행 단계 pill 확인
- 폼 제출 시연 (데모 계정은 항상 성공 처리)

### Step 4 — 마이페이지 (`/mypage`)
- 총 자산 요약 카드 확인
- 투자 중인 작품 리스트 확인
- 기록 섹션 링크 확인

### Step 5 — 지갑 (`/wallet`)
- 총 평가 자산 + 수익률 확인
- 입금/교환/출금 CTA 확인
- 보유 종목 리스트 확인

## 6. 각 화면에서 반드시 보여줄 포인트 3개씩

### 홈 (`/`)
1. 히어로 영상 + 블루/퍼플 그라디언트 → "내가 좋아하는 크리에이터와 동업자가 되고." 헤드라인
2. 추천 큐레이팅 레일 → 실제 K-콘텐츠 IP 종목 카드 (자연화된 제목)
3. 시장 동향 → 아이콘 micro-motion + 4개 타일

### 대표 상세 (`/market/[id]`)
1. 현재가 카드 (가격 + 변동률) → 금융형 데이터 느낌
2. 살까말까 탭 → **투자설명서 PDF full-width 카드** (핵심 CTA)
3. 거래하기 탭 → 매수/매도 주문 패널

### KYC (`/kyc`)
1. 상태 배지 (심사 전 → 심사 중 → 승인 흐름)
2. 진행 단계 pill 3개 (compact 구조)
3. 폼 제출 → 즉시 상태 전환

### 마이페이지 (`/mypage`)
1. 총 자산 수치 + 수익률 인라인 표시
2. 투자 중인 작품 리스트 (종목명 + 수익률)
3. 기록 섹션 → 주문/정산/입출금 링크

### 지갑 (`/wallet`)
1. 총 평가 자산 + 미실현손익 수치
2. 입금/교환/출금 CTA 3버튼
3. 보유 종목 리스트 (실제 포지션)

## 7. 캡처 전 확인 포인트

- [ ] 히어로 영상 재생 중인지 (검정 배경 아님)

- [ ] PDF 카드가 정보/소개 섹션 하단에 full-width로 표시되는지
- [ ] 시장 동향 아이콘이 micro-motion 중인지
- [ ] 마이페이지 자산 요약 카드 수치 표시 확인
- [ ] 지갑 보유 종목 1건 이상 표시 확인
- [ ] KYC 상태 배지 정상 표시 확인
- [ ] 모든 페이지에서 FloatingSupportDock 표시 확인 (로그인 페이지 제외)

## 8. 대표 상세에서 꼭 보여줄 블록 순서

```
1. 헤더 (종목명 + 현재가 카드)
2. 살까말까 탭 선택
   → 정보/소개 카드 (한 줄 소개 + 프로젝트 개요)
   → 투자설명서 PDF 카드 (full-width, 다운로드 CTA)
   → 살까말까 카드 (투자 포인트 / 리스크 / 로드맵)
3. 지금얼마 탭 선택
   → 현재가 3개 미니 카드
   → 가격 차트 (60틱 기본)
4. 거래하기 탭 선택
   → 주문 패널 (매수/매도)
```

## 11. 데모 중 클릭 순서

```
홈(/)
  → 히어로 CTA "투자 시작" 클릭 (또는 "둘러보기")
  → 마켓 목록(/market)
  → 대표 종목 클릭 (/market/[id])
  → 살까말까 탭 → PDF 카드 → 지금얼마 탭 → 거래하기 탭
  → 하단 네비 "마이" 클릭 → 마이페이지(/mypage)
  → KYC 인증 링크 → KYC 페이지(/kyc)
  → 하단 네비 "지갑" 클릭 → 지갑(/wallet)
```

## 12. 데모 후 Q&A 대비 포인트

| 예상 질문 | 대응 포인트 |
|---|---|
| "실제 거래가 되나요?" | 현재 시뮬레이션 모드. 실거래는 KYC 승인 후 활성화 예정 |
| "수익은 어떻게 정산되나요?" | 매월 25일 콘텐츠 수익 자동 정산 → 지갑으로 입금 |
| "KYC는 얼마나 걸리나요?" | 제출 후 1~2 영업일 내 심사 완료 |
| "블록체인 연동은?" | KCP 블록체인 기반 소유권 기록 (/feature/blockchain 참고) |
| "모바일 앱은 없나요?" | 현재 모바일 웹 최적화. 앱 출시 로드맵 있음 |
| "투자 한도는?" | KYC 미인증: 소액 한도 / KYC 승인: 한도 상향 |
| "PDF 투자설명서는 실제 문서인가요?" | 현재 데모용 문서. 실서비스 시 실제 투자설명서로 교체 예정 |
