# HANBANG 데모 동선 체크리스트

> 내부 실무용 · 투자자/파트너 데모 전 반드시 확인

---

## 1. 데모 목적

- K-콘텐츠 IP 수익권 거래 플랫폼의 핵심 UX 흐름을 5분 이내로 전달
- "홈 진입 → 종목 탐색 → 거래 → 자산 확인" 동선의 완성도 증명
- 투자자/파트너에게 서비스 첫인상과 금융형 UI 완성도를 보여주는 것이 목적

---

## 2. 데모 시작 URL

```
https://[배포 도메인]/
```

- 로컬: `http://localhost:3000/`
- 데모 계정 사전 로그인 필수 (아래 준비 체크리스트 참고)

---

## 3. 추천 동선 (5단계)

### Step 1 — 홈 (`/`)
- 히어로 섹션 (블루/퍼플 시네마틱 배경 + 영상)
- 추천 큐레이팅 레일 스크롤
- "지금 주목받는 콘텐츠" 그리드 확인

### Step 2 — 대표 상세 (`/market/[id]`)
- 추천 종목: `여행가 제이` (블루웨이 시즌3) 클릭
- 살까말까 탭 → 실험결과 / 지급예측 확인
- 지금얼마 탭 → 가격 차트 + 체결 흐름 확인
- 거래하기 탭 → 주문 패널 확인

### Step 3 — KYC (`/kyc`)
- 마이페이지 → KYC 인증 진입
- 상태 카드(심사 전/심사 중/승인) 확인
- 본인 정보 입력 폼 compact 구조 확인
- 제출하기 버튼 클릭 (데모 계정은 항상 성공 처리)

### Step 4 — 마이페이지 (`/mypage`)
- 총 자산 요약 카드 (투자중 / 출금가능 / 수익)
- 투자 중인 작품 리스트
- 기록 (주문내역 / 정산내역 / 입출금기록) 링크

### Step 5 — 지갑 (`/wallet`)
- 총 평가 자산 + 수익률 카드
- 입금 / 교환 / 출금 CTA 버튼
- 보유 종목 리스트
- 최근 배당 / 거래 기록

## 4. 각 화면에서 반드시 보여줄 포인트

### 홈 (`/`)
1. 히어로 영상 + 블루/퍼플 그라디언트 → "프리미엄 금융 서비스" 첫인상
2. 추천 큐레이팅 레일 → 실제 K-콘텐츠 IP 종목 카드
3. 마감 임박 섹션 → 긴박감 + 투자 유도 CTA

### 대표 상세 (`/market/[id]`)
1. 현재가 + 변동률 카드 → 실시간 금융 데이터 느낌
2. 살까말까 탭 → 실험결과 / 지급예측 데이터 카드 밀도
3. 거래하기 탭 → 매수/매도 주문 패널 (업비트형 UX)

### KYC (`/kyc`)
1. 상태 배지 (심사 전 / 심사 중 / 승인) → 진행 상태 명확
2. 진행 단계 pill 배지 → 3단계 흐름 한눈에
3. 폼 제출 → 즉시 상태 전환 확인

### 마이페이지 (`/mypage`)
1. 총 자산 수치 + 수익률 인라인 표시
2. 투자 중인 작품 리스트 → 종목명 + 수익률 배지
3. 기록 섹션 → 주문/정산/입출금 링크

### 지갑 (`/wallet`)
1. 총 평가 자산 + 미실현손익 → 금융형 수치 강조
2. 입금/교환/출금 CTA 3버튼 → 행동 유도
3. 보유 종목 리스트 → 실제 포지션 표시

## 5. 데모 중 리스크 포인트

| 리스크 | 대응 방법 |
|---|---|
| 영상(hero.mp4) 로딩 지연 | 미리 탭 열어두고 캐시 확보 |
| API 응답 지연 (지갑/포트폴리오) | 로딩 스켈레톤 보이는 동안 설명으로 채우기 |
| KYC 미인증 상태에서 거래 시도 | "KYC 인증 후 거래 가능" 안내 메시지 활용 |
| 모바일 화면 비율 차이 | iPhone 14 Pro 기준으로 시연 권장 |
| 빈 포트폴리오 (데모 계정 미투자) | 사전에 mock 투자 1건 이상 세팅 |

- [ ] 브라우저 확대/축소 100% 고정
- [ ] 불필요한 탭 닫기 (성능 확보)
- [ ] 네트워크 상태 확인 (API 응답 속도)
- [ ] KYC 상태를 "심사 전" 또는 "승인"으로 세팅 (시나리오에 따라)

## 7. 데모 중 클릭 순서

```
홈(/) 
  → 히어로 CTA "지금 투자 시작" 클릭 (또는 마켓 둘러보기)
  → 마켓 목록(/market) 
  → 대표 종목 클릭 (/market/[id])
  → 살까말까 탭 → 지금얼마 탭 → 거래하기 탭
  → 하단 네비 "마이" 클릭 → 마이페이지(/mypage)
  → KYC 인증 링크 → KYC 페이지(/kyc)
  → 하단 네비 "지갑" 클릭 → 지갑(/wallet)
```

## 8. 데모 후 Q&A 대비 포인트

| 예상 질문 | 대응 포인트 |
|---|---|
| "실제 거래가 되나요?" | 현재 시뮬레이션 모드. 실거래는 KYC 승인 후 활성화 예정 |
| "수익은 어떻게 정산되나요?" | 매월 25일 콘텐츠 수익 자동 정산 → 지갑으로 입금 |
| "KYC는 얼마나 걸리나요?" | 제출 후 1~2 영업일 내 심사 완료 |
| "블록체인 연동은?" | KCP 블록체인 기반 소유권 기록 (/feature/blockchain 참고) |
| "모바일 앱은 없나요?" | 현재 모바일 웹 최적화. 앱 출시 로드맵 있음 |
| "투자 한도는?" | KYC 미인증: 소액 한도 / KYC 승인: 한도 상향 |
