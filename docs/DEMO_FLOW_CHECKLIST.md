# HANBANG 데모 동선 체크리스트

> 내부 실무용 · 투자자/파트너 데모 전 반드시 확인  
> 최종 업데이트: 2026-03-11 (데모 계정 데이터 세팅 점검 1차 반영)

---

## 1. 데모 목적

- K-콘텐츠 IP 수익권 거래 플랫폼의 핵심 UX 흐름을 5분 이내로 전달
- "홈 진입 → 종목 탐색 → 거래 → 자산 확인" 동선의 완성도 증명
- 투자자/파트너에게 서비스 첫인상과 금융형 UI 완성도를 보여주는 것이 목적

## 3. 데모 계정 준비 상태 체크리스트

### 필수 항목

| 항목 | 필요 상태 | 확인 방법 | 비어 있을 경우 영향 |
|---|---|---|---|
| **로그인** | 완료 | `/wallet` 접근 시 리다이렉트 없으면 OK | 홈 MyAssetCard가 가입 유도 UI로 표시됨 |
| **보유 종목** | 1건 이상 | `/wallet` → 보유 종목 섹션 | "첫 번째 콘텐츠 자산을 소유해보세요" EmptyState 표시 |

| **KYC 상태** | 심사 전 또는 승인 | `/kyc` → 상태 배지 | 어떤 상태든 UI는 정상 표시 |
| **홈 mock 데이터** | 항상 정상 | 홈 진입 후 큐레이팅 레일 카드 표시 확인 | mock 기반이므로 항상 표시됨 |
| **상세 mock 데이터** | 항상 정상 | `/market/[id]` 진입 후 가격/차트 표시 | mock 기반이므로 항상 표시됨 |
| **마이페이지 자산** | 항상 정상 | `/mypage` → 총 자산 카드 | mock 기반(₩15,820,000)이므로 항상 표시됨 |
| **마이페이지 투자 리스트** | 항상 정상 | `/mypage` → 투자 중인 작품 | mock 기반(3종목)이므로 항상 표시됨 |

## 4. 데모 직전 3분 체크리스트

```
□ 브라우저 로그인 상태 확인 (/wallet 접근 가능한지)
□ 히어로 영상 캐시 확보 (홈 한 번 미리 방문 → 새로고침)
□ 대표 상세 URL 미리 열어두기 (/market/[id] — 블루웨이 시즌3 권장)
□ DevTools 모바일 뷰 설정 (iPhone 14 Pro, 390px) 또는 실기기 준비
□ 브라우저 확대/축소 100% 고정
□ 불필요한 탭 닫기 (API 응답 속도 확보)
□ 네트워크 상태 확인 (Wi-Fi 권장)
□ 데모 계정에 보유 종목 1건 이상 세팅 확인
```

## 7. 대표 상세에서 꼭 보여줄 블록 순서

```
1. 헤더 (종목명 + 현재가 카드 + 변동률)
   → "청약 + 거래형 · 수익 배분형 · 거래소 UI" 칩 확인

2. 살까말까 탭 선택 (기본값)
   → 정보/소개 카드 (한 줄 소개 + 프로젝트 개요)
   → ★ 투자설명서 PDF 카드 (full-width, 다운로드 CTA) ← 반드시 보여줄 것
   → 살까말까 카드 (투자 포인트 / 리스크 / 로드맵)

3. 지금얼마 탭 선택
   → 현재가 3개 미니 카드 (현재가/변동/체결 흐름)
   → 가격 차트 (60틱 기본)
   → 체결 흐름 카드

4. 거래하기 탭 선택
   → 주문 안내 카드
   → 주문 패널 (매수/매도 입력 + 수량 스텝퍼 + 제출 버튼)
```

## 8. 추천 동선 (5단계)

### Step 1 — 홈 (`/`)
- 히어로 영상 + "내가 좋아하는 크리에이터와 동업자가 되고." 헤드라인
- "투자 시작" / "둘러보기" CTA 버튼
- 추천 큐레이팅 레일 스크롤 → 시장 동향 micro-motion 확인

### Step 2 — 대표 상세 (`/market/[id]`)
- 블루웨이 시즌3 클릭
- 살까말까 → PDF 카드 → 지금얼마 → 거래하기 순서

### Step 3 — KYC (`/kyc`)
- 상태 배지 + 진행 단계 pill 확인
- 폼 제출 시연

### Step 4 — 마이페이지 (`/mypage`)
- 총 자산 ₩15,820,000 + 3종목 투자 리스트 확인

### Step 5 — 지갑 (`/wallet`)
- 총 평가 자산 + 입금/교환/출금 CTA 확인
- 보유 종목 리스트 확인

## 10. 데모 후 Q&A 대비 포인트

| 예상 질문 | 대응 포인트 |
|---|---|
| "실제 거래가 되나요?" | 현재 시뮬레이션 모드. 실거래는 KYC 승인 후 활성화 예정 |
