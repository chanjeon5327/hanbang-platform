# HANBANG 플랫폼 아이덴티티 정의

> 유튜브 링크 6개(업비트 가이드) + 토스·넷플릭스 벤치마킹 분석 결과

## 1. 벤치마킹 분석 요약

| 소스 | 핵심 톤 | 적용 범위 |
|------|---------|-----------|
| **업비트 가이드 6편** | 거래·전문성·데이터 밀도·호가/차트·다크·실시간 | market 상세, 호가창, 지갑 |
| **토스** | 신뢰·금융·밝음·정적·깔끔 | 메인·마이페이지·정적 화면 |
| **넷플릭스** | 큐레이션·콘텐츠 카드·시각 임팩트 | 레일·히어로·첫 화면 |

## 2. HANBANG 아이덴티티 (한 줄)

> **"디지털 IP 수익권을 금융처럼 믿고, 거래처럼 쓸 수 있는, 콘텐츠처럼 보는" 플랫폼**

## 3. 비주얼 원칙

1. **신뢰(토스)**: 밝은 배경, 흰 카드, 파란 포인트, 둥근 모서리
2. **거래(업비트)**: 데이터 밀도, 수치 강조, 테이블형 레이아웃, 호가 색상(매수 파랑·매도 빨강)
3. **큐레이션(넷플릭스)**: 레일 가로 스크롤, 썸네일 비율 4:5, H 폭발급 히어로

## 4. 메인 페이지 적용

- 히어로: 강한 그라데이션 + 글래스모피즘 + CTA
- 스탯 배너: 오늘 거래량·누적 수익 등 신뢰 지표
- 레일: 카드 그림자·호버·그라데이션 오버레이
- 섹션: 배지·아이콘·리본으로 시각적 계층
