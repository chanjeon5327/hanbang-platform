# HANBANG 캡처 대상 목록

> 투자자/파트너 데모 자료 및 내부 문서용 스크린샷 기준

---

## 캡처 기준

- 기기: **모바일 우선** (iPhone 14 Pro, 390×844px) / PC는 별도 표기
- 브라우저: Chrome DevTools 모바일 뷰 또는 실기기
- 배율: 100% (2x 레티나 권장)
- 상태: 로그인 완료 + 데이터 로딩 완료 후 캡처

---

## 캡처 목록

### 1. 홈 첫 화면

| 항목 | 내용 |
|---|---|
| **경로** | `/` |
| **캡처 상태** | 페이지 로딩 완료, 히어로 영상 재생 중 (첫 프레임 또는 2~3초 시점) |
| **왜 필요한가** | 서비스 첫인상. 블루/퍼플 금융형 히어로 톤이 제대로 보이는지 확인 |
| **우선 기기** | 모바일 (390px) |
| **비고** | 히어로 + 마켓 티커바 + 추천 큐레이팅 레일 상단 일부가 한 화면에 보여야 함 |

---

### 2. 홈 히어로 클로즈업

| 항목 | 내용 |
|---|---|
| **경로** | `/` |
| **캡처 상태** | 히어로 섹션만 확대 캡처 (스크롤 최상단) |
| **왜 필요한가** | 헤드라인 문구 + CTA 버튼 + 배경 그라디언트 품질 확인 |
| **우선 기기** | PC (1280px 이상) |
| **비고** | "내가 좋아하는 콘텐츠 사고 팔고, 매달 수익을 받습니다." 문구 선명하게 |

---

### 3. 대표 상세 첫 화면

| 항목 | 내용 |
|---|---|
| **경로** | `/market/[id]` (여행가 제이 / 블루웨이 시즌3 권장) |
| **캡처 상태** | 페이지 진입 직후, 살까말까 탭 기본 선택 상태 |
| **왜 필요한가** | 종목 헤더 (현재가 카드 + 변동률) + 탭 UI + 첫 카드 밀도 확인 |
| **우선 기기** | 모바일 (390px) |
| **비고** | 현재가 카드와 탭 버튼이 한 화면에 보여야 함 |

---

### 4. 대표 상세 — 거래 패널

| 항목 | 내용 |
|---|---|
| **경로** | `/market/[id]` → 거래하기 탭 |
| **캡처 상태** | 거래하기 탭 클릭 후, 주문 패널 완전히 로딩된 상태 |
| **왜 필요한가** | 매수/매도 주문 UI (업비트형) + 호가창 밀도 확인 |
| **우선 기기** | 모바일 (390px) |
| **비고** | 주문 입력 필드 + 수량 스텝퍼 + 제출 버튼이 한 화면에 보여야 함 |

### 5. 대표 상세 — 지금얼마 탭 (차트)

| **비고** | 폼 전체가 한 화면에 보이면 이상적. 스크롤 없이 CTA까지 보이면 최상 |
