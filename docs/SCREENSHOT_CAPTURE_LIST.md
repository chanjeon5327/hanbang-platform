> 최종 업데이트: 2026-03-11 (데모 계정 데이터 세팅 점검 1차 반영)

---

## 캡처 기준

- 기기: iPhone 14 Pro 기준 (390×844px) — 모바일 우선
- 브라우저: Chrome DevTools 모바일 뷰 또는 실기기
- 확대/축소: 100% 고정
- 다크모드: 시스템 라이트 모드 기준
- 로그인 상태: 데모 계정 로그인 완료 후 캡처

---

## 캡처 전 데이터 상태 확인

```
□ 데모 계정 로그인 완료
□ 보유 종목 1건 이상 세팅 확인 (/wallet → 보유 종목 표시 여부)
□ 홈 히어로 영상 캐시 확보 (미리 방문 후 새로고침)
□ 대표 상세 URL 확인 (블루웨이 시즌3 권장)
□ 마이페이지 mock 수치 정상 표시 확인 (₩15,820,000)
□ 시장 동향 micro-motion 동작 확인 (홈 스크롤)
□ PDF 카드 full-width 표시 확인 (상세 → 살까말까 탭)
```
